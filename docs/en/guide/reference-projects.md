### Update and validation ownership

- PRs changing public APIs, features, export protocols, schema or lifecycle update crate docs, tested examples and this index. Link affected consumers' pinned revisions/PRs and actual test results. Consumers own product configuration and role matrices.
- Merge, dependency resolution, library tests, consumer tests, release artifacts and production rollout are distinct evidence. Mark unknowns unverified and local patch/WIP explicitly; neither is published Git adoption.
- Run `bun run docs:build` in `docs/` to run `docs:check-evidence` for required index fields, bilingual pinned revisions and Forge source paths, then check internal links and build rustdoc. Reuse consumer test scripts without fetching every product on each Forge PR. Drive's offline documentation check constrains bilingual baselines and lock revisions; static checks do not establish protocol behavior or collector delivery.
- #44's core is implemented; remaining acceptance does not mean Drive is unmigrated. #45's tracing/layers remain future work. Current `init_logging()` installs a global subscriber; existing logging spans do not establish OTel export support.
